# Licence origin and destination parsing

Release 0.13.0 distinguishes explicit licence issuing-country phrases from destination geography. Previously, every driving question asked for the issuing country, even when supplied, and an origin such as UK could cause Toronto to be treated as unsupported.

Recognized phrases include country/adjective followed by licence (optionally driving or driver), licence from a country, and licence issued in/from/by a country. Since 0.19.27 the alias set covers 201 issuing countries and territories: 24 have dedicated licensing records and 177 have a broad national, government or state information entry point. This list is language parsing coverage only; it does not indicate exchange agreements, licence-specific guidance or legal eligibility.

Only the country span attached to an explicit origin phrase is excluded from unsupported-destination detection. A separate unsupported location remains a reason to clarify. A bare phrase such as driving licence in UK remains destination context. Nationality alone does not establish the issuing country. Unrecognized origins still trigger the existing question, multiple origins request disambiguation, and missing destinations still require location.

Parsed results now expose `licenceCountry` and `licenceCountryAmbiguous`. This is single-request extraction, not persistent conversation memory. The trace logger does not add these fields or raw questions to its stored payload. No user profile, licence number or document is collected. No evidence or approval status changes.

The licence-context suite covers explicit aliases, origin/destination separation, ambiguity, missing slots, word boundaries and similar-name collisions. Since 0.19.7, when a question names a recognized issuing country, retrieval also cites that country's licensing record where one exists (see `COVERAGE_EXPANSION.md`): India's Parivahan/Sarathi, GOV.UK's DVLA licence-share service, the Philippines' LTO LTMS portal and Punjab's DLIMS. Since 0.19.27, the other 177 countries cite a broad national, government or state information entry point instead. Those records are explicitly **not** verified licence pages, and the tests pin that they produce no public claims. All 397 project tests and both development evaluation datasets (28 pilot / 68 expanded) pass. This remains narrow rule parsing; broad language understanding, robust multi-turn clarification and licence-specific research for the new portal countries remain pending. Driving records still await independent factual review.
